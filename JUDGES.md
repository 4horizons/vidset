# Judge demo — no setup

## [⬇ Download the demo (.zip)](https://github.com/4horizons/vidset/releases/download/judge-demo/VIDSET-DEMO.zip)

1. Download and unzip.
2. Double-click **START-HERE.html**. If it opens as text, right-click → **Open with → Safari / Chrome / Edge**.
3. Click **Watch the 60s demo** or **What we built**.

No server, installation, login, API keys, or model calls. All videos and images are included, so the demo works offline.

The beach result, Q&A, and app model selection are recorded. Prelint is connected for routing-policy review; the app makes the selection. We will demonstrate new uploads and generation in the live app.

See [README.md](README.md#run-the-live-app--macos--linux) only if you want to run the live application yourself.
