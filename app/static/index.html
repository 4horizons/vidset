    BUILD YOUR MODEL TEAM

    Models & keys

    Connect the models that see, reason, and create. OpenAI can handle both vision and reasoning, with Higgsfield editing the source video. Keys are held in server memory for this session, never returned to the browser or saved to disk.

    Provider connections

    For Higgsfield, enter your own API ID and secret together as API_ID:API_SECRET. Local credentials are separate from any connected Codex account.

    Assign each role

    One FAL_KEY can power video analysis, chat, and source editing through the fal.ai model gateway.

    Source editing sends the selected original clip and instruction to your selected source video provider. The fal.ai model gateway can route vision and reasoning to distinct models with one key. Anchor generation uses OpenAI image editing and a fal.ai model that supports first and last frames. Model IDs are editable; use endpoints supported by each provider.

    Blank keys keep existing connections.
